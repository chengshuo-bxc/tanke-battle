# 坦克大战 · Battle City

经典坦克大战游戏的浏览器复刻版，使用纯 HTML + Canvas + JavaScript 实现，无需任何外部依赖，开箱即玩。

## 快速开始

直接用浏览器打开 `index.html` 即可开始游戏。

## 操作方式

| 按键 | 功能 |
|------|------|
| `↑ ↓ ← →` | 移动坦克 |
| `空格` | 射击 |
| `P` | 暂停/继续 |

## 游戏特性

- **敌人类型**：基础（灰色）、快速（红色）、重装（绿色）、Boss（深色，高血量）
- **道具系统**：火力升级⭐、护盾🛡️、加速⚡、全屏炸弹💣、额外生命❤️
- **关卡递增**：每通关一关自动进入下一关，难度逐步提升
- **迷你地图**：右上角实时显示战场全景
- **连击加分**：连续击杀敌人可获得额外分数倍率
- **最高分**：成绩自动保存在浏览器本地

## 技术实现

- 纯前端游戏，单 HTML 文件，零依赖
- Canvas 2D 渲染，支持粒子爆炸和护盾特效
- Web Audio API 音效（射击、爆炸、道具拾取等）
- 基于种子的随机地图生成，每关地图结构不同
- 道具悬浮动画和消失倒计时
- 坦克精灵通过 Canvas 绘制，包含履带动画
